# Client Locator

Независимый **серверный** мод для NeoForge 1.21.11. Он не изменяет PlatinumSuite и
не требует установки на клиент.

## Команда

```text
/playerlocate <игрок>
```

Команда показывает текущее измерение, точные координаты и координаты блока
указанного игрока. Игрок должен быть онлайн. Команда не требует OP, но доступна
только UUID владельца, указанному в конфигурации. Для остальных игроков команда
не отображается и не выполняется. Ванильная команда `/locate` не изменяется.

## Настройка владельца

1. Один раз запустите сервер с модом, затем остановите его.
2. Откройте созданный файл `config/client-locator.properties`.
3. Укажите свой UUID без кавычек:

   ```properties
   allowed-uuids=12345678-1234-1234-1234-123456789abc
   ```

   Несколько разрешённых UUID можно перечислить через запятую. Используйте UUID
   именно с вашего сервера — его можно найти в `usercache.json`.
4. Сохраните файл и перезапустите сервер. Если список пуст или UUID записан с
   ошибкой, команда будет недоступна всем.

Пример ответа:

```text
Игрок Steve находится в измерении minecraft:the_nether на координатах 12.50, 64.00, -8.25 (блок 12 64 -9)
```

## Сборка и установка

### Скачать из GitHub Actions

1. Откройте вкладку **Actions** репозитория.
2. Выберите успешный запуск **Build mod**.
3. В разделе **Artifacts** скачайте архив `client-locator-neoforge-1.21.11`.
4. Распакуйте архив и перенесите находящийся внутри JAR в папку `mods` сервера.
5. Запустите сервер на NeoForge для Minecraft 1.21.11. Дополнительные библиотеки
   устанавливать не нужно.

GitHub Actions собирает мод с JDK 21 и Gradle 8.14.4. Artifact содержит только
готовый мод: архивы `sources` и `javadoc` в него не добавляются.

### Собрать локально

1. Установите 64-битный JDK 21 и Gradle 8.14.4.
2. Проверьте установку командами `java -version` и `gradle --version`.
3. В корне проекта выполните `gradle build`.
4. После сообщения `BUILD SUCCESSFUL` возьмите готовый мод из
   `build/libs/client-locator-1.0.0.jar` и перенесите его в папку `mods` сервера.

Не переносите на сервер JAR с суффиксом `-sources`: он содержит только исходный
код и не является модом.

Для разрешённого UUID выдавать права оператора не нужно.
